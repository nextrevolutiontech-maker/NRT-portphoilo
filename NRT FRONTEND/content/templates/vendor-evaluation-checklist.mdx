# ERP Vendor Evaluation Checklist

Choosing an ERP vendor is a 5-to-10 year marriage. If you select a vendor based solely on the initial licensing cost, you risk severe technical debt and vendor lock-in. Use this checklist to objectively score potential partners.

## 1. Technology & Architecture
- [ ] **API First:** Does the system provide comprehensive REST or GraphQL APIs for custom integrations?
- [ ] **Cloud Native:** Is the system built for the cloud, or is it a legacy on-premise system hosted on a virtual machine?
- [ ] **Database Integrity:** Does the system use a strict, relational database (like PostgreSQL) to guarantee ACID compliance for financial ledgers?

## 2. Security & Compliance
- [ ] **Role-Based Access Control (RBAC):** Can you restrict user access at a granular field level?
- [ ] **Audit Trails:** Is every database change logged immutably with a timestamp and user ID?
- [ ] **Data Ownership:** Does the contract explicitly state that you own your data and can export it in a standard format (CSV/JSON) at any time without a fee?

## 3. Implementation Methodology
- [ ] **Phased Rollout:** Does the vendor support modular implementations, or do they force a "Big Bang" launch?
- [ ] **Process Mapping:** Does the vendor dedicate Phase 1 entirely to mapping your "As-Is" business processes?
- [ ] **Customization Limits:** Is the system rigid, or can business logic be customized without breaking future software updates?

## 4. Support & Maintenance
- [ ] **SLA:** Is there a legally binding Service Level Agreement (SLA) for system uptime (e.g., 99.9%)?
- [ ] **Bug Fixes vs Feature Requests:** Does the vendor clearly define the pricing difference between fixing a bug (which should be free) and building a new feature?
