# NRT Content Playbook

## Tone and Voice
- Enterprise, authoritative, and objective.
- Avoid marketing fluff (e.g., "We are the best..."). Use evidence ("Our recent deployment reduced...").
- Keep sentences concise. Use formatting (bold, lists) for readability.

## Audience
- **Primary:** C-Suite (CEO, CTO, CFO). Focus on ROI, Security, and Scalability.
- **Secondary:** Operational Managers. Focus on Workflows, Automation, and Errors.

## Evidence Engine Rules
1. Never make a numeric claim without an `evidence` block in the MDX frontmatter.
2. If citing an external statistic, link directly to the primary source.
3. If citing NRT data, use the `Internal Case Study` or `Benchmark` evidence type.
