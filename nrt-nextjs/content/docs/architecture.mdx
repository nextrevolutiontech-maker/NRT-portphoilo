# Content Engine Architecture

The NRT Content Engine is a highly scalable, local headless CMS built on top of the Vite ecosystem. 

## The Four Engines

1. **Content Engine**: Parses MDX, validates metadata via Zod, and builds search indexes.
2. **Rendering Engine**: Consumes loaded modules and renders them via React.
3. **AI Engine**: Builds context windows from relationships in the metadata.
4. **SEO Engine**: Generates sitemaps, RSS, and schemas at build-time.

## Directory Structure

We strictly separate UI code (`/src`) from data (`/content` and `/data`). 
This ensures we can migrate to a Next.js monorepo seamlessly in the future.
